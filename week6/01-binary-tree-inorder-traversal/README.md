# Binary Tree Inorder Traversal

For this problem, I needed to visit all nodes of a binary tree in inorder sequence. The order is left subtree, current node, and right subtree. I solved it first with recursion. If the current node is null, the method returns. Otherwise, it visits the left child, adds the current value to the result list, and then visits the right child. I also implemented an iterative version using a stack. I keep moving to the left child and pushing nodes onto the stack. When there is no left child, I take a node from the stack, add its value, and continue with its right subtree. Both approaches visit every node once, so the time complexity is O(n). The space complexity is O(h) for the recursion stack or the explicit stack, where h is the height of the tree.
