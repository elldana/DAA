# Remove Duplicates from Sorted List

## 1. Problem
Нам дан отсортированный по возрастанию связный список. Нужно удалить из него все повторяющиеся значения, чтобы каждое число встречалось ровно один раз, и вернуть список

## 2. Approach
Так как список изначально отсортирован, все одинаковые элементы стоят подряд друг за другом. Это сильно упрощает задачу:
1. Если список пустой (`head == null`), сразу возвращаем `null`.
2. Ставим указатель `current` на голову списка `head`.
3. Запускаем цикл `while (current != null && current.next != null)`.
4. Сравниваем текущее значение со следующим (`current.val == current.next.val`):
   - Если они равны, просто переставляем указатель: `current.next = current.next.next`. Мы как бы выкидываем дубликат из цепочки. При этом сам `current` не двигаем, потому что за дубликатом может идти еще один такой же дубликат!
   - Если значения разные, тогда смело сдвигаем `current = current.next`.
5. Возвращаем `head`.

### Tracing Example
Пример: `head = [1, 1, 2, 3, 3]`

- **Старт**: `current` на первой `1`. `current.next` указывает на вторую `1`.
- **Шаг 1**: Значения равны (`1 == 1`).  
  Делаем `current.next = current.next.next` (теперь первая `1` указывает на `2`).  
  Список: `[1 -> 2 -> 3 -> 3]`. `current` все еще на первой `1`.
- **Шаг 2**: Сравниваем `1` и `2`. Не равны.  
  Сдвигаем `current = current.next` (теперь `current` на `2`).
- **Шаг 3**: Сравниваем `2` и `3`. Не равны.  
  Сдвигаем `current` на первую `3`.
- **Шаг 4**: Сравниваем первую `3` и вторую `3`. Равны.  
  `current.next = null` (перепрыгнули вторую тройку).  
  Список: `[1 -> 2 -> 3]`.
- **Шаг 5**: `current.next == null`, цикл завершен.  
  Результат: `[1, 2, 3]`.

### Challenges & Mistakes
- В первой попытке я внутри `if (current.val == current.next.val)` сразу делала и `current.next = current.next.next`, и тут же сдвигала `current = current.next`. Из-за этого тест со списком `[1, 1, 1]` ломался и выдавал `[1, 1]`, потому что алгоритм перепрыгивал одну единицу и не успевал проверить третью. Пришлось убрать смещение `current` в ветку `else`.
- Также сначала забыла проверить крайний случай с пустым списком (`head == null`) и на пустом тесте получила `NullPointerException`.

## 3. Time Complexity
**Time Complexity: O(n)**, где $n$ — количество узлов в списке.  
**Why:** Мы проходим по списку одним указателем ровно один раз слева направо. Даже если мы удаляем элементы, общее число проверок не превышает количества элементов.

## 4. Space Complexity
**Space Complexity: O(1)**  
**Why:** Мы не создаем новые списки и не выделяем память под массивы. Используется только один вспомогательный указатель `current`.
