# Remove Linked List Elements

## 1. Problem
Дан односвязный список и число `val`. Нужно удалить из списка абсолютно все узлы, у которых значение равно `val`, и вернуть обновленный список

## 2. Approach
Главная трудность задачи — удалить узел, если он стоит в самом начале (голова списка), или если вообще весь список состоит из удаляемых чисел (например `[7, 7, 7]`). Чтобы не писать гору `if-else` условий, я использовала прием с фиктивным узлом (`dummy head`):

1. Создаем узел `dummy = new ListNode(0)`.
2. Привязываем его к нашей голове: `dummy.next = head`.
3. Указатель `current` ставим на `dummy`.
4. В цикле проверяем следующий узел (`current.next`):
   - Если `current.next.val == val`, мы просто удаляем его, перенаправляя стрелку: `current.next = current.next.next`. Мы остаемся на месте, чтобы на следующем круге проверить новый узел, вставший на это место.
   - Если значение нормальное, сдвигаемся вперед: `current = current.next`.
5. Возвращаем `dummy.next` (настоящую новую голову).

### Tracing Example
Пример: `head = [1, 2, 6, 3, 4]`, `val = 6`

- **Старт**: `dummy -> 1 -> 2 -> 6 -> 3 -> 4`. `current` на `dummy`.
- **Шаг 1**: `current.next.val == 1` ($\ne 6$). Сдвиг: `current` на 1.
- **Шаг 2**: `current.next.val == 2` ($\ne 6$). Сдвиг: `current` на 2.
- **Шаг 3**: `current.next.val == 6` ($== 6$!).  
  Делаем `current.next = current.next.next` (ссылка с 2 перенаправляется сразу на 3).  
  `current` остается на 2!
- **Шаг 4**: `current.next.val == 3` ($\ne 6$). Сдвиг: `current` на 3.
- **Шаг 5**: `current.next.val == 4` ($\ne 6$). Сдвиг: `current` на 4.
- `current.next == null` -> цикл завершен.  
- Возвращаем `dummy.next` -> `[1, 2, 3, 4]`.

### Challenges & Mistakes
- В первой версии без фиктивного узла я пыталась делать цикл в стиле `while (head != null && head.val == val) head = head.next;`. Это работало для головы, но код получался запутанным, легко было словить `NullPointerException` при обращении к `.val`. 
- С фиктивным узлом `dummy` логика стала единой для абсолютно всех элементов: голова обрабатывается точно так же, как середина или хвост.

## 3. Time Complexity
**Time Complexity: O(n)**, где $n$ — количество узлов в списке.  
**Why:** Мы за один проход осматриваем каждый узел списка. Количество действий пропорционально длине списка.

## 4. Space Complexity
**Space Complexity: O(1)**  
**Why:** Мы создали ровно один вспомогательный узел `dummy` и одну переменную `current`. Мы меняем только связи между узлами в памяти.
